Real-World Problem: Package Delivery

A delivery company must deliver packages in the given order within a limited number of days. Find the minimum truck capacity required.

Understand Binary Search on Answer Space

1. What is Binary Search?

Binary Search is an efficient searching technique. Instead of checking every possible value one by one, it checks the middle value and reduces the search range.

2. What is Binary Search on Answer Space?

Sometimes we need to find the minimum or maximum possible answer to a problem. We can use Binary Search on the range of possible answers.

In our package delivery problem, we need to find the minimum truck capacity required to deliver all packages within the given number of days.

3. Understand Low, High and Mid

  • Low: The smallest possible truck capacity. It is the weight of the heaviest package.
  • High: The largest possible truck capacity. It is the total weight of all packages.
  • Mid: The middle capacity we are checking.

4. What is the Feasibility Check?

We check whether the truck can deliver all packages within the allowed number of days using the selected capacity.

  • If the capacity is valid, save the answer and search for a smaller capacity.
  • If the capacity is invalid, increase the capacity and search the right side.

5. When does Binary Search stop?

Binary Search stops when Low becomes greater than High. The saved answer is the minimum valid truck capacity.

6. Real-world example

Imagine a delivery company needs to deliver packages within five days. It wants to use the smallest possible truck capacity to save transportation costs. Binary Search helps find that minimum capacity efficiently.

Time and Space Complexity

1. What is Time Complexity?

Time Complexity explains how the running time of an algorithm grows as the input size increases.

2. Time Complexity of Binary Search on Answer Space

In our problem, we search for the minimum truck capacity between Low and High.

Binary Search divides the search range approximately in half during every iteration.

Time Complexity: O(n × log(S - M + 1))

  • n: Number of packages.
  • S: Sum of all package weights.
  • M: Maximum package weight.
  • log: Number of times the search range is halved.

Why O(n × log(S - M + 1))? Each Binary Search iteration runs the feasibility check, which visits all n packages. The number of iterations depends on the size of the capacity search range.

3. What is Space Complexity?

Space Complexity explains how much additional memory an algorithm uses as the input size grows.

Auxiliary Space Complexity: O(1)

Our feasibility check and Binary Search use only a fixed number of extra variables such as Low, High, Mid, Days Needed and Current Load.

Note: This O(1) space does not include the input package list or the memory used to store the result.

4. Why is Binary Search efficient?

Checking every possible capacity one by one can be slow. Binary Search reduces the search range in every iteration, making it much more efficient.

5. Complexity Summary

  • Feasibility Check: O(n)
  • Binary Search Iterations: O(log(S - M + 1))
  • Overall Time Complexity: O(n × log(S - M + 1))
  • Auxiliary Space Complexity: O(1)
